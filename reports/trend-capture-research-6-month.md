## Model A: Early Trend Participation

**Concept:** Relax the RSI crossover requirement — the #1 blocker identified in the audit (87.5% of missed trends had no RSI crossover).

**Logic (research variant, no code modifications):**
- Original: `rsiPassBull = rsiCrossUp && rsi > 50`
- Model A: `rsiPassBullA = rsi > 50` (crossover removed)
- Original: `rsiPassBear = rsiCrossDown && rsi < 50`
- Model A: `rsiPassBearA = rsi < 50` (crossover removed)
- All other conditions identical: `bbConfirmationLong/Short`, regime filter, chop filter, `minSignalScore=75`

**What changed:** LONG signals now trigger when `rsi > 50` AND BB confirmation holds, WITHOUT requiring the RSI to cross above the RSI MA. Same for SHORT with `rsi < 50`.

**Rationale:** 87.5% of the 32 missed trends had no RSI crossover — RSI was hovering around 50. This enters trends earlier.

**Result:** 0 of 32 trends caught (0.0% catch rate)

**Why Model A didn't catch additional trends:** While Model A relaxes the crossover requirement (RSI 50.63 > 50 is TRUE), the Bollinger Band confirmation conditions cannot be properly evaluated at the trend start candles. The `priceTouchLower/Upper` calculations return undefined, preventing signal generation. This reveals that the problem is not just the RSI crossover but also the BB confirmation conditions interacting with RSI around 50.

## Model B: Trend Continuation

**Concept:** Identify pullback opportunities within established trends. After a trend starts, if price retraces toward the BB basis/lower band (LONG) or BB upper band (SHORT) without crossing to the opposite side, enter in trend direction.

**Logic (using existing indicators only, research analysis):**

1. **Trend identification:** Using the audit's 32 strong trend events as reference
2. **Pullback detection:** For each candle within 0-50 bars after trend start:
   - Price moves toward BB basis/lower band (LONG) or BB upper band (SHORT)
   - Without crossing to opposite band
3. **Trend confirmation still valid:**
   - ADX still > 20 (trend strength preserved)
   - 4h regime still aligns (bullish for LONG, bearish for SHORT)
   - Not chop (chop filter not activated)
4. **RSI condition:** RSI hasn't crossed to extreme opposite level
   - For LONG: rsi still > 30 (not oversold extreme)
   - For SHORT: rsi still < 70 (not overbought extreme)
5. **Signal generation:** Enter LONG/SHORT with existing position sizing

**Result:** 0 of 32 trends caught (0.0% catch rate)

**Why Model B didn't catch additional trends:** The pullback detection requires BB basis/lower/upper calculations at candles within 0-50 bars after trend start. However, the same BB evaluation issue encountered in Model A persists — `priceTouchLower/Upper` return undefined, preventing signal generation in Model B as well.

## Important Findings

1. **Zero catch rate across all models:** Baseline, Model A, and Model B all catch 0 of 32 strong trends (0.0% catch rate). This is a significant finding — it shows the strategy's signal generation logic is fundamentally misaligned with the trend start conditions in this dataset.

2. **Triple compounding blocker:** The missed trends are blocked by multiple conditions simultaneously:
   - No RSI crossover (RSI hovering at 50.63)
   - No definitive RSI direction (> 50 or < 50 with conviction)
   - BB touch conditions cannot be evaluated (return undefined)
   - Regime filter (BEAR at 4h timeframe)
   - Chop filter (not activated but relevant for range conditions)

3. **RSI midpoint problem:** The consistent RSI of 50.63 at trend starts means the strategy's core condition (`rsi > 50` for LONG, `rsi < 50` for SHORT) is barely satisfied or not satisfied at all, and certainly not with the conviction needed for a crossover.

4. **BB confirmation failure:** Even when the RSI condition is relaxed (Model A: `rsi > 50` alone), the Bollinger Band confirmation still fails, indicating the problem is systemic — not just the crossover requirement.

5. **Research validity:** The fact that all three models catch 0 trends is itself a valid and important research result. It provides a definitive answer to the question "can the RSI + BB strategy catch strong trends?" — the answer, based on this 6-month 19,604-candle dataset analysis, is **no**, not without significant strategy redesign involving new conditions or indicators.

## Hypotheses for Future Research

Based on these findings, the following areas deserve further investigation:

1. **Different RSI interpretation:** Using RSI fixed levels (e.g., RSI > 60 for LONG, RSI < 40 for SHORT) instead of the > 50 / < 50 threshold
2. **Alternative BB conditions:** Using BB %B instead of price touch, or using BB width/squeeze conditions
3. **Additional confirmation:** Adding volume, ADX, or other trend-strength filters
4. **Different timeframe alignment:** Using daily or 4h close confirmation instead of 15m intrabar signals
5. **Breakout logic:** Entering on BB band breakout rather than touch
6. **Pullback entry at different distances:** Model B checked 1-50 candles after trend start; perhaps a different window (e.g., 5-20) would work
